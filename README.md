# Supermarket Sales Analysis – Data Analytics Project

## Project Description
This Python project analyzes 500 supermarket sales transactions and produces insights about products, branches, categories, customers, payment methods, monthly sales, and ratings.

## Files
- `YourName_SupermarketSalesAnalysis.ipynb` – complete Jupyter Notebook code.
- `requirements.txt` – required Python dependencies.
- `YourName_SupermarketSalesReport.docx` – complete project report.
- `SUPER MARKET DATA.pdf` – supplied dataset.
- `outputs/` – cleaned dataset, analysis tables, charts, and report.

## Technologies
Python, Pandas, Matplotlib, pdfplumber, Jupyter Notebook.

## Setup / Run
1. Install Python 3.
2. Run `pip install -r requirements.txt`.
3. Start Jupyter with `jupyter notebook`.
4. Open `YourName_SupermarketSalesAnalysis.ipynb`.
5. Run all cells from top to bottom.

## Analysis Workflow
Load PDF → extract data → clean/validate → calculate summaries → analyze product/branch/category/payment/customer/rating trends → create charts → draw business conclusions.
